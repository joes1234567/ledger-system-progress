系統現在能做什麼 vs 還做不到

✅ 能做（已完成）
  • Email + 密碼登入、4 角色 RBAC、多角色聯集

  • 送審記帳（draft → pending_review）
  • 核准 / 退回記帳（原因必填、寫 review_log + audit）
  • 作廢 approved 記帳（admin only、D6 作廢→重建）
  • 取消送審（建立者撤回 pending → draft）
  • 審核者部門 scope 可見性（只看授權部門待審）
  • 並發保護：同時審同一筆 → 409 + review_conflict audit
  • 審核歷程查詢（建立者 / reviewer / admin 各依權限）
  • 可見≠可改授權（看得到他人單但不能竄改 / 軟刪）
  • 附件上傳 / 下載 / 軟刪（MIME 雙驗 / 5 上限 / lifecycle）
  • audit log 全部重要操作（append-only、含失敗下載）
